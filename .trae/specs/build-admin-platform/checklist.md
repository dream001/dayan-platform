# 验收清单

- [ ] 前端使用 Vue 3、TypeScript 和 Vite，后端使用 Java 21、Spring Boot 3 和 MyBatis-Plus
- [ ] 后端代码按 Controller、Service、Repository/Mapper、Model 分层，DTO/VO 未与持久化实体混用
- [ ] PostgreSQL 迁移可在空库完整执行，重复启动不会覆盖已有业务数据
- [ ] 登录、刷新、退出、密码修改、账号禁用和未认证响应符合规格
- [ ] 密码与刷新令牌均未以明文存储，接口错误不泄露内部堆栈或敏感配置
- [ ] 用户、角色、部门、菜单和按钮权限均使用真实 PostgreSQL 数据完成管理
- [ ] 后端对每个受保护接口执行权限校验，无权限请求返回 403 且不产生业务变更
- [ ] 前端导航来自当前用户菜单树，操作按钮依据权限码显示或隐藏
- [ ] 用户、角色、菜单、部门之间的删除和关联约束正确生效
- [ ] 文件对象实际存入 MinIO，文件元数据实际存入 PostgreSQL
- [ ] 文件上传失败不会遗留不完整对象或元数据，下载、预览和删除均经过权限校验
- [ ] 登录及关键写操作生成可筛选的审计日志，密码、令牌等敏感数据未写入日志
- [ ] 工作台统计来自真实数据库数据，不存在 Mock、硬编码业务列表或占位接口
- [ ] 管理端覆盖登录、工作台、个人中心、用户、角色、菜单、部门、文件和操作日志页面
- [ ] 页面具备一致的加载、空数据、成功、失败和危险操作确认状态
- [ ] 桌面与窄屏下导航、筛选、表格、弹窗和文本无不可用遮挡或异常布局跳动
- [ ] 前端单元测试、类型检查、代码检查和生产构建通过
- [ ] 后端单元测试、集成测试和构建通过
- [ ] 浏览器自动化验证登录、动态权限、用户授权和文件上传下载关键流程通过
- [ ] Docker Compose 可从空数据卷启动 PostgreSQL、MinIO、后端和前端，全部健康检查通过
- [ ] 容器重启后 PostgreSQL 数据和 MinIO 文件保持存在
- [ ] 环境变量示例不包含真实密钥，初始化管理员凭据可配置且有修改提示
